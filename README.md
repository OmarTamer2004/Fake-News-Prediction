**📰 Fake News Prediction using NLP & Logistic Regression**

This project builds a machine learning model to detect fake news based on text content using Natural Language Processing (NLP) and a Logistic Regression classifier.
The workflow includes data preprocessing, text cleaning, stemming, TF-IDF vectorization, model training, and evaluation.

📂 Dataset

The dataset consists of news articles with the following columns:

Column	Description
author	Name of the writer
title	Title of the news article
text/content	Full content (generated by combining author & title)
label	0 = Real News, 1 = Fake News

The file is loaded from:

/content/drive/MyDrive/train.csv

🧹 NLP Preprocessing Steps

The text content is processed with:

✔️ Cleaning

Removing all non-alphabet characters

Converting to lowercase

✔️ Removing Stopwords

Using NLTK’s English stopwords list

✔️ Stemming

Using Porter Stemmer to reduce words to root form

✔️ TF-IDF Vectorization

Text → TF-IDF numeric features

🤖 Model Used
Logistic Regression

Ideal for binary classification problems (Fake vs Real).

Steps:

Train/test split (80/20)

Fit model using TF-IDF vectors

Predict labels for train & test data
